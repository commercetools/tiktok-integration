## What needs a decision, and whose

1. **Gate 0, roadmap overlap (product side).** This is a TikTok Shop connector. Someone on the product side has to confirm it does not overlap the roadmap. Not cleared, so I can't call it publishable.
2. **History goes public (you).** `origin/main` has one commit, but this checkout's history also holds "old projects", "plans" and "plan" commits, which contain the old plan files and the old router. Publish a squashed history, or confirm the older commits are fine to show.
3. **Repository name (you).** `tiktok-integration` is on the sweep's company-name list. TikTok is a platform rather than a customer, so this is probably fine. It is flagged medium.

## What a script can fix

- **SPDX header** is missing from 232 of our own source files. Run `apply_fixes.py . --apply` and then run the build and tests, because a header placed above a `"use client"` line breaks a file.
- **README** lacks License and Support sections.
- **CONTRIBUTING.md** lacks the SPDX header requirement and the right-to-license statement.

## Vendored SDK

`shared/tiktok-sdk/` (2480 tracked files) is the TikTok Shop SDK generated by openapi-generator. It is vendored unmodified, with `VENDORED.md`, but it carries **no LICENSE file**. The header pass should not add our header to it. Someone has to confirm TikTok's SDK terms allow redistribution in a public repository, and add its licence text or a note to `VENDORED.md`.
