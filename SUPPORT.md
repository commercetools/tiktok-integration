# Support

Thanks for using this project. A few honest words about what to expect.

## What this is

This is a commercetools-labs project: reference code we are glad to share. It is freely available under the
[MIT License](LICENSE), provided **as is**, and **not supported by commercetools**. There is no support contract, no
SLA, and no promise of fixes, releases or roadmap alignment. It is not an official commercetools product and it is not
certified for the Connect marketplace.

You are welcome to use it, fork it and adapt it. Please test it against your own project and TikTok shop before you
rely on it for real orders.

## Where to get help

- **Read the docs first:** [README](README.md), [docs/setup.md](docs/setup.md), [docs/webhooks.md](docs/webhooks.md), [docs/token-storage-security.md](docs/token-storage-security.md).
- **Questions and ideas:** open a GitHub issue. Other users and the maintainers read them when time allows, with no guaranteed reply.
- **Bugs:** open an issue with what you did, what you expected, what happened, and the relevant log lines. Remove tokens, secrets, shop ids and customer data first.
- **Fixes:** pull requests are welcome, see [CONTRIBUTING.md](CONTRIBUTING.md).

## Please do not use issues for

- Problems with the commercetools platform, Connect or the Merchant Center themselves: use your commercetools support channel.
- Problems with TikTok Shop, your partner app review or your seller account: use TikTok Shop Partner Center support.
- Security reports. Do not post secrets or exploit details in a public issue. Use GitHub's private vulnerability reporting for this repository if it is enabled, or contact commercetools through its security disclosure process.
